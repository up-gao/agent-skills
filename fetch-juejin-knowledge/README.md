# fetch-juejin-knowledge

将掘金（juejin.cn）文章/专栏/用户文章列表转换为本地 Markdown 文件，图片全部下载到本地，路径使用绝对路径。

## 功能介绍

- **单篇文章采集**：输入掘金文章链接，生成带元数据的 Markdown 文件
- **批量采集**：支持多个文章链接一次性批量处理
- **用户文章列表采集**：输入用户主页链接，自动拉取该用户全部已发布文章
- **专栏采集**：输入专栏链接，获取专栏下全部文章（优先使用 SSR 数据，备用方案转为用户列表采集）
- **图片本地化**：文章中的图片自动下载到本地，使用时间戳命名，路径替换为绝对路径
- **元数据保留**：保留作者、发布时间、标签、阅读量、点赞数、收藏数、评论数等元数据
- **限速控制**：自动添加请求间隔，避免触发 API 限流
- **失败记录**：抓取失败的文章 URL 和错误原因自动记录到日志文件

## 使用说明

### 基本用法

直接向 Claude 提供掘金链接即可：

```
帮我采集这篇掘金文章 https://juejin.cn/post/7665184555516395555
```

### 指定输出目录

```
帮我把这篇文章保存到 /Users/me/docs/ 目录下
https://juejin.cn/post/7665184555516395555
```

### 批量采集多篇文章

```
帮我采集以下掘金文章，保存到 ./juejin-articles/：
- https://juejin.cn/post/7665184555516395555
- https://juejin.cn/post/7668704642685632552
- https://juejin.cn/post/7538761538192343040
```

### 采集某位作者的全部文章

```
帮我采集这个掘金作者的全部文章 https://juejin.cn/user/3793793900098220
```

### 采集专栏

```
帮我采集这个掘金专栏 https://juejin.cn/column/7003686944504774663
```

## 输出格式

```
输出目录/
├── 文章标题.md
└── images/
    ├── image-20260802150432001.awebp
    ├── image-20260802150432002.png
    └── ...
```

Markdown 文件结构：

```markdown
# 文章标题

> 原文链接：https://juejin.cn/post/xxx
> 作者：xxx | 发布时间：2024-01-15 10:30:00
> 标签：123456, 789012
> 阅读：1000 | 点赞：50 | 收藏：20 | 评论：10

正文内容...

![图片描述](/绝对路径/images/image-20260802150432001.png)
```

## 技术说明

### API 接口

掘金公开的内容 API：

- **文章详情**：`POST https://api.juejin.cn/content_api/v1/article/detail`
  - 返回的 `mark_content` 字段已是完整 Markdown 格式
- **用户文章列表**：`POST https://api.juejin.cn/content_api/v1/article/query_list`
  - 支持分页，返回所有已发布文章

### 依赖

- `curl` — API 请求和图片下载
- `python3` — 数据处理和文件生成

### 注意事项

- 掘金页面（HTML）有反爬保护，curl 直接访问会返回"找不到页面"，但 API 接口正常可用
- 图片格式通常为 `.awebp`（一种 WebP 变体），部分图片查看器可能不支持
- 批量采集建议每次不超过 50 篇，大量采集请分批进行
